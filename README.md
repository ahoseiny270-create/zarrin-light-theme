## 🆕 تغییرات نسخه ۱.۵.۰

* **نرخ طلا هر ۱۰ دقیقه** (کش سرور + کرون وردپرس + مرورگر) — قبلاً ۹۰ ثانیه بود
* **اسلایدر چنداسلایدی** بنر اصلی با تا ۳ اسلاید قابل ویرایش + تیکر متحرک نرخ
* **بلوک‌های جدید صفحه اصلی**: اسلایدر نظرات مشتریان، آکاردئون سوالات متداول، محاسبه‌گر قیمت طلا
* **مشخصات تخصصی طلا** برای هر محصول: عیار، وزن، اجرت ساخت، درصد سود، شناسنامه/کد رهگیری
* **صفحات ورود/ثبت‌نام، سبد خرید، تسویه حساب و فاکتور** با اعتبارسنجی موبایل و کد ملی
* **منوی همبرگری کشویی**، نوار شناور موبایل، نوار چسبان «افزودن به سبد»
* **سئو**: Open Graph، Twitter Card و داده ساختاریافته Product / Store / نرخ روز
* **فوتر چهارستونه قانونی** (قوانین فروش، بازگشت کالا، حریم خصوصی، پیگیری سفارش) + نشان‌های اعتماد
